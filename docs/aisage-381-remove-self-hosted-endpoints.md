# AISAGE-381 — Remove self-hosted model-catalog endpoint calls

## Summary

The Anaconda AI SDK (`anaconda-ai`) called the self-hosted-only model-catalog
endpoint `GET /org/models/model-data` from `AICatalystClient.models.list`.
That endpoint is being removed as part of stripping self-hosted-only features
from the model-catalog service, so the SDK was repointed to the shared
`GET /models` **version:3** endpoint.

Only one call site existed in this repository. It has been repointed, and the
request now pins the model-catalog API version to `3` via the
`X-Anaconda-Api-Version` header.

## Changes made

`src/anaconda_ai/clients/ai_catalyst.py` — `AICatalystModels.list`:

1. URL changed from `/api/ai/model/org/models/model-data` to
   `/api/ai/model/models`.
2. The API version is pinned per-request with
   `headers={"X-Anaconda-Api-Version": "3"}`, following the existing
   per-endpoint version override pattern already used by
   `AICatalystModels.download_collection` (which pins `"1"` for the collection
   manifest/download endpoints).
3. `GET /models` v3 paginates (default `limit=100`, maximum `1000`), whereas
   `model-data` returned every model in a single response. To preserve the
   previous "list all models" semantics the method now pages with
   `limit=1000` / increasing `offset` until a short page is returned.
   Note the v3 response's `total` equals the size of the returned page (not the
   collection-wide count), so termination is keyed on `len(page) < limit`.

`tests/test_ai_catalyst_models.py` (new) — covers the repointed URL, the pinned
version header, the requested `limit`/`offset` params, and the pagination loop.

## Gaps / follow-ups

- **Policy metadata is preserved, so no `TODO(AISAGE-381)` was required.**
  In the model-catalog service, `GET /models` version:3 and
  `GET /org/models/model-data` version:3 both serialize the same
  `PublishedModelV3` contract (`domain/contracts/models/_shared_v3.py`), and
  `list_models_v3` applies the same `apply_policies_to_models` enrichment in
  self-hosted mode. The `policy` block consumed by
  `AICatalystQuantizedFile.is_allowed` (`is_blocked`,
  `missing_license_acceptance`, `download_status`, `allowed_groups`) therefore
  remains populated. Behavior relying on `is_allowed` is unchanged.
- `GET /models` version:3 also calls `populate_download_urls_for_model_files`,
  adding a `download_url` to file entries. The SDK ignores this field (it builds
  its own download URL), so this is a benign superset.
- The pagination cap per request is `1000`. If a deployment ever exposes more
  than 1000 models the loop still retrieves all of them; only the number of
  round-trips scales.
